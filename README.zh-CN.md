# 琪琪（chichi）

[English](README.md) | 中文

在 Linux 桌面上把安卓手机里的单个应用开成独立窗口。点「淘宝」弹出淘宝，点「Word」弹出 Word，每个应用一个窗口，互不干扰，手机自己的屏幕也不受影响。也能像普通 scrcpy 一样镜像整个手机屏幕。

原理是 [scrcpy](https://github.com/Genymobile/scrcpy) 的虚拟显示：为每个应用在手机上新建一块看不见的屏幕，把应用放上去，再把这块屏幕投到电脑上。

## 解决什么问题

很多日常事务只有手机 App：聊天、银行、购物、外卖、播客……在 Linux 电脑上，现有办法都不太对劲：镜像整个手机只有一个手机形状的窗口，一次只能用一个 App，电脑上的操作也在你口袋里的手机上同步发生；模拟器 / Waydroid 是另一部要配置、登录的手机，很多 App 不让跑；网页版要么没有，要么是缩水版。

琪琪借鉴 Windows 上 RemoteApp / WinApps 的思路：App 照常跑在你真实的手机上、用你真实的账号，但每个 App 在电脑上都是一个普通窗口，可以摆放、缩放、Alt+Tab 切换，几个并排开着，手机本身还能腾出来干别的。同时把直接用 scrcpy 不顺手的地方都处理掉了：一键打开、声音只转一份并可选在哪响、手机息屏也能点、在手机上点图标就把 App 收回、记住无线连接过的手机、额外屏幕、按手机分开的设置。

## 前提

**只有一个：安卓手机，并且打开了 USB 调试**（「设置 → 关于手机」连点版本号打开开发者选项，再在「开发者选项」里打开「USB 调试」）。

不需要 root，不需要在手机上装任何东西。不同的系统版本能用的功能不同，版本不够时程序会直接告诉你，不会莫名失败：

| 功能 | 手机系统 |
|---|---|
| 镜像整个手机屏幕 | 安卓 5 以上 |
| 单独开应用窗口 | 安卓 10 以上 |
| 声音转到电脑 | 安卓 11 以上 |
| 声音手机和电脑两边都响 | 安卓 13 以上 |
| 无线连接（「无线调试」配对方式） | 安卓 11 以上；更老的手机可用 `adb tcpip 5555` 方式 |

电脑这边需要：

| 软件 | 说明 |
|---|---|
| Linux 桌面 | 在 Ubuntu 26.04 + KDE Plasma（Wayland）上开发和测试；其它桌面应该也能用，托盘图标需要桌面支持 StatusNotifierItem |
| adb | `sudo apt install adb` |
| scrcpy 3.0 以上 | 建议用 [官方 Linux 版](https://github.com/Genymobile/scrcpy/releases)（自带依赖，系统升级不会坏）。开发和测试用的是 4.1 |
| nmap | 可选，无线连接时自动找端口：`sudo apt install nmap` |

界面支持简体中文、繁体中文、英文、日文、韩文、德文、法文、意大利文、西班牙文、阿拉伯文，默认跟随系统语言，可在设置里切换。

## 安装

### .deb 安装包（推荐，Ubuntu / Debian）

```bash
sudo apt install ./chichi_0.1.0_amd64.deb
```

装好后在开始菜单里搜「琪琪」或「chichi」。

### AppImage

```bash
chmod +x chichi-0.1.0-x86_64.AppImage
./chichi-0.1.0-x86_64.AppImage
```

AppImage 在新版 Ubuntu 上有两个坑，所以只作为备用：

- 需要 `libfuse2`（Ubuntu 22.04 起默认不带）：`sudo apt install libfuse2t64`，或者加参数 `--appimage-extract-and-run` 运行。
- Ubuntu 24.04 起限制普通程序使用用户命名空间，Electron 的沙箱会启动失败，报错里有 `chrome-sandbox`。解决办法见下面「常见问题」。

### 从源码运行

```bash
git clone <仓库地址> chichi
cd chichi
npm install
npm start
```

加到开始菜单：`npm run install-desktop`（写 `~/.local/share/applications/chichi.desktop`；移除：`bash scripts/install-desktop.sh --remove`）。菜单启动的是编译好的版本，改了代码要 `npm run build`。

## 怎么用

两个页面：

- **常用**
  - 顶部「整个手机屏幕」：镜像手机的实际屏幕，就是 scrcpy 最基本的用法。
  - 「额外屏幕」：给手机加一块新屏幕，上面是手机的副屏桌面（三星手机上是 DeX 桌面），可以在上面开任意应用。窗口可以拖动、最大化，手机上的屏幕跟着变大。关掉时上面开着的应用会挪回手机，不会被结束。需要安卓 10 以上；桌面应用不支持副屏的手机上，这块屏幕可能是空白的（打开时会提示）。
  - 「声音在」：手机 / 电脑 / 两边，点一下立刻切换。
  - 下面是你挑出来的应用。点一行在下面展开，里面有「打开 / 关闭窗口」，以及这个应用的窗口尺寸、横竖屏、大小（固定 / 可拖动）、置顶、移除。
- **设置**：顶部是界面语言和外观（跟随系统 / 浅色 / 深色），下面分四栏
  - **应用**：手机上的所有应用，可以搜索，点「添加」放进常用。系统应用默认隐藏。
  - **窗口**：默认窗口尺寸、自定义尺寸、键盘与输入法、息屏唤醒、返回键行为、额外 scrcpy 参数。
  - **声音**：声音在哪儿响、缓冲大小、关窗口时是否暂停播放。
  - **连接**：无线连接、adb 与 scrcpy 的位置和检测。

改动即时保存，不需要点保存按钮。

**设置跟着手机走。** 常用列表、默认窗口尺寸、声音、键盘、手机相关选项，每部手机各有一份；界面语言、外观、自定义尺寸、无线地址、程序位置是共用的。手机按序列号识别，同一部手机 USB 和无线连接算同一部。第一次连上的手机常用列表是空的，可以在「设置 → 应用」里从另一部手机复制（点两次确认覆盖）。列表里这部手机没装的应用会标出来，打不开。同时连着几部手机时，在右上角切换。

**截图**：每个开着的窗口，在常用列表那一行的末尾有「截图」按钮（「整个手机屏幕」卡片上也有），托盘菜单里也有「截图」子菜单。截的是手机上那块屏幕的原始画面，分辨率比电脑上的窗口高，存到「图片 / chichi」文件夹并复制到剪贴板。

**在手机上收回应用**：电脑上开着某个应用时，在手机桌面上点它的图标，这个应用会回到手机屏幕上（页面状态保留），电脑上的窗口随之关掉。只认手机默认桌面里的点击，应用之间的正常跳转不受影响。

**在手机上断开**：连上后手机通知栏会出现一条「琪琪已连接」。划掉它，电脑上开着的应用都会回到手机上；无线连接会同时断开，不用去关无线调试。USB 连接没法从手机上断开，划掉只会把应用收回来；拔掉数据线后这条通知可能留着，手动划掉即可。

**关掉主窗口只是藏到系统托盘**，已经打开的手机窗口和声音照常运行。点托盘图标显示/隐藏主窗口，右键菜单里选「退出」才真正结束（会先暂停正在播放的应用，再关掉所有手机窗口）。程序同时只开一个，已经开着时再从开始菜单点，会把原来的窗口调出来。

### 窗口尺寸

内置尺寸（竖屏数值，横屏自动对调）：

| 名称 | 像素 | dpi | App 看到的屏幕 |
|---|---|---|---|
| 跟随手机 | 打开时读取手机当前屏幕 | | |
| iPhone 17 | 1206 × 2622 | 480 | 402 × 874 |
| iPhone Air | 1260 × 2736 | 480 | 420 × 912 |
| iPhone 17 Pro Max | 1320 × 2868 | 480 | 440 × 956 |
| Pixel 10 | 1080 × 2424 | 420 | 411 × 923 |
| iPad Air 11 英寸 | 1640 × 2360 | 320 | 820 × 1180 |
| 电脑屏 1080p | 1080 × 1920 | 240 | 720 × 1280 |

每个应用还可以选**大小：固定 / 可拖动**。选「可拖动」时，拖动窗口边缘，手机那边的屏幕跟着变大变小，App 按新大小重新排版；上面选的尺寸只决定刚打开时多大。（内部让窗口的 1 个物理像素对应手机上的 1 个像素，dpi 随桌面缩放比例调高，所以 150%、200% 缩放的屏幕上也清楚，窗口多宽 App 就按多宽排版。桌面有缩放时，可拖动窗口刚打开可能比选的尺寸矮一些，往高拖就行。）

「App 看到的屏幕」决定 App 按多宽的屏幕来排版：宽度 = 像素 ÷ (dpi ÷ 160)。手机一般在 360–440 之间，数值越大一屏显示的内容越多、字越小。要加别的尺寸，在「设置 → 窗口 → 自定义尺寸」里填。

### 声音

| 声音在 | 说明 |
|---|---|
| 手机 | 默认。声音留在手机上，电脑不出声 |
| 电脑 | 有窗口开着时，整部手机的声音转到电脑上，手机静音 |
| 两边 | 手机和电脑同时响；个别禁止被录音的应用只在手机上响 |

不管开了几个窗口，声音只转一份（scrcpy 抓的是整机声音、分不出应用）。几个应用同时出声时交给手机系统处理：音乐、播客、视频类应用大多会互相让，一个开始播另一个自动暂停。没法按「哪个窗口在前台」切换声音。

缓冲「大 / 中 / 小」是 250 / 120 / 50 毫秒，无线连接有爆音就调大。

**关窗口时暂停播放**（默认开）：关的只是窗口，应用不会被杀；如果它正在播放就发一个暂停，免得转到后台接着播。

### 键盘与输入法

| 电脑键盘 | 说明 |
|---|---|
| 普通（默认） | 只能传英文字符。电脑输入法打出的中文传不过去（scrcpy 的限制），需要中文时在电脑上复制、在窗口里按 Ctrl+V 粘贴 |
| 模拟外接键盘 | 按键原样传给手机，由手机输入法出拼音候选，中文能打；操作手机窗口时把电脑输入法切到英文。**副作用**：窗口开着期间手机一直以为接着实体键盘，直接用手机时 Gboard 等输入法会隐藏屏幕键盘 |

### 手机

| 选项 | 说明 |
|---|---|
| 手机息屏时自动唤醒 | 手机锁屏息屏时，窗口里的应用能看不能点。开着这项时，打开应用前、以及你在窗口里点击或按键时发现手机睡着了，都会自动叫醒它，那一下点击会在手机醒来后（约半秒）补发过去，点一次就够。手机醒着时不做任何事，不影响你直接用手机 |
| 退到桌面时拉回应用 | 一直按返回，窗口会退到手机的副屏桌面（三星上是 DeX 桌面）；开着这项时约 1 秒内把应用拉回原来的页面。应用自己跳到别的应用（比如淘宝跳支付宝）不受影响 |

### 无线连接

USB 插上会自动识别。走无线时：

1. 手机打开「开发者选项 → 无线调试」。第一次需要先在 USB 下授权过这台电脑，或者在终端里 `adb pair <地址:配对端口>` 配对一次（界面里没有配对功能）。
2. 「设置 → 连接」里填手机地址。「端口」可以填范围（默认 32768-60999），也可以直接填手机「无线调试」页面上显示的端口号。
3. 点「连接」。程序会依次尝试：已连上就直接用 → 上次成功的端口 → 用 nmap 扫描（顺带扫老式 `adb tcpip` 用的 5555 端口）。

无线连上过的手机（不管是琪琪连的还是别的工具连的）会按手机记住地址，列在「设置 → 连接」顶上的「已记住的手机」里，以后点那一行的「连接」就行，不用再填地址；没连上手机时常用页顶部也有这几部手机的连接按钮。手机重启或重开无线调试后端口会变，点「连接」时会自动重新扫描。不会在后台自动重连。不想要的点「忘记」。

### 配置文件

`~/.config/chichi/config.json`，可以手改，支持 `//` 注释和尾逗号。格式写坏时程序会把它改名备份成 `config.json.broken-时间戳`，然后用默认设置启动。

## 常见问题

**从开始菜单点了没反应，日志里有 `chrome-sandbox ... is owned by root and has mode 4755`**

Ubuntu 24.04 起限制普通程序使用用户命名空间，Electron 的沙箱起不来。.deb 安装包会自动处理这个问题；从源码运行或用 AppImage 时，给 Electron 程序加一条 AppArmor 放行规则（Ubuntu 给 VS Code 用的是同样的办法），把路径换成你实际的 electron 位置：

```bash
sudo tee /etc/apparmor.d/chichi-electron >/dev/null <<'EOF'
abi <abi/5.0>,
include <tunables/global>

profile chichi-electron /path/to/chichi/node_modules/electron/dist/electron flags=(unconfined) {
  userns,
  include if exists <local/chichi-electron>
}
EOF
sudo apparmor_parser -r /etc/apparmor.d/chichi-electron
```

**窗口里点不动**：手机息屏了。开着「手机息屏时自动唤醒」（默认开）时，点一下约半秒后就会生效；关着的话在窗口里按一下鼠标右键唤醒。

**直接用手机时屏幕键盘不见了**：你选了「模拟外接键盘」，改回「普通」，或者关掉所有手机窗口。

**声音断断续续**：「设置 → 声音」里把缓冲调到「大」。

**点「检测」提示 scrcpy 版本太旧**：系统软件源里的 scrcpy 可能是 2.x，换成官方 Linux 版。

## 已知限制

- 从托盘退出琪琪时，它打开的手机窗口会一起关掉。只关主窗口不会。
- 同一个应用同时只开一个窗口；已经开着的应用再点「打开」没法把它的窗口提到前台。
- 关窗口时的暂停，是向手机发一个系统级的「暂停」媒体键。只有确认这个应用正在播放才会发，但如果恰好有两个应用同时在播，暂停的可能是另一个。
- 同时连着多台手机时，声音只转其中一台（第一个打开窗口的那台）。
- 额外的 scrcpy 参数按空格切分，不支持带空格的参数值。
- 在手机上点图标收回应用，只认手机默认桌面里的点击；用别的方式打开（最近任务、通知、别的应用跳转）不会收回。

## 开发

```bash
npm run build   # 编译到 dist/
npm test        # 离线测试，不需要手机
tools/package.sh --snapshot   # 按当前工作区试打包，成品放 release/
tools/package.sh              # 正式打包：从最新提交构建（工作区必须干净）
```

架构、设计决策和不变量见 [CLAUDE.md](CLAUDE.md)，版本变化见 [CHANGELOG.zh-CN.md](CHANGELOG.zh-CN.md)。

发布包只从 git 里的源码、在临时目录里构建，成品里的每个文件都要过私人信息和密钥扫描，通过了才放进 `release/`。新克隆后先启用一次提交钩子：`git config core.hooksPath .githooks`。

界面文案在 `locales/<语言>.json`，以 `zh.json` 为准；加文案时十个文件都要加，`npm test` 会检查键和占位符是否一致。翻译由 AI 完成，欢迎母语使用者纠正。
